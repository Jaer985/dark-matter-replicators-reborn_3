Version: 4.6.0
Date: 2026-10-24
  Features:
    - The Quality Refiner is AUTOMATIC. No more recipe to choose: insert any replicable item and the
      machine walks it up one quality level at a time, on its own. The machine keeps a single hidden
      fixed recipe (empty by design) so it still needs power and still animates, and the mod gains
      its first runtime script (one table pass every 0.5 s, only over refiners holding an item).
    - One attempt per tier per second: 1 s for tier-1 items up to 5 s for tier-5. Chances are
      unchanged (5 % / 2.5 % / 1.25 % / 1 % by step, 1 % destruction), the ladder never skips, and
      the top quality simply has no next step.
    - The quality ladder is built from the game's own quality prototypes ordered by level, so mods
      that add or reorder quality levels get a working chain instead of being ignored.
  Changes:
    - Removed the per-item, per-step refining recipes (~800 recipes on a small modlist) and the
      machine picker with them: the 4.1.0 "empty picker" class of bug cannot come back.
    - Closed an exploit: recipes pinned the input quality with `ingredients[].quality`, which is not
      a gate in Factorio 2.1 (the real filter is `quality_min`/`quality_max`), so a normal item could
      be pushed through the legendary step. There are no steps to pick now — the script reads the
      item's actual quality and only ever advances it by one level.

      re-routes any orphaned grouped tech as designed. The same mechanism
      generalizes to any other mod that deletes vanilla/moddable techs — add an
      optional dependency to force load order.
